In the last lesson, time told the LED what to do. In this lesson, you do.

## What you need

- Everything from [your first flow](/docs/learn/first-flow).
- A push-button, also called a momentary switch.
- A 10 kΩ pull-down resistor.
- A breadboard and four jumper wires.
- An LED and a 220 Ω resistor. You can reuse the built-in LED on pin 13 instead.

## Step 1 — Wire the button

A button alone is not enough. Without a pull-down resistor, pin 2 floats between values when the button is up.

| Connection | From | To |
| --- | --- | --- |
| Power | 5V | One side of the button |
| Signal | The other side of the button | Pin 2, and one end of the 10 kΩ resistor |
| Ground | The other end of the 10 kΩ resistor | GND |

Pressing the button connects 5 V to pin 2. Releasing it connects pin 2 to ground through the resistor.

<Callout type="info" title="No resistor? Use the internal pull-up">
Wire the button between pin 2 and GND, then turn on the Button node's **Pull-up** setting. The board uses its own resistor, and the reading inverts: pressed reads `LOW`. Turn on **Invert** to flip it back.
</Callout>

## Step 2 — Wire the LED

Skip this step if you reuse the built-in LED on pin 13.

| Connection | From | To |
| --- | --- | --- |
| Signal | Pin 9 | One leg of the 220 Ω resistor |
| LED | The other leg of the resistor | The long leg of the LED |
| Ground | The short leg of the LED | GND |

## Step 3 — Build the flow

1. Add a [Button](/docs/microflow-studio/nodes/sense/button) node and set **Pin** to `2`.
2. Add an [LED](/docs/microflow-studio/nodes/express/led) node and set **Pin** to `9`, or `13` if you skipped step 2.
3. Draw an edge from the Button node's `true` output to the LED node's `true` input.
4. Draw a second edge from `false` to `false`.

Draw both edges. The first switches the LED on. The second switches it off. With only the first edge, the LED comes on and stays on.

## Step 4 — Test it

Press the button. The LED switches on. Release the button. The LED switches off.

If nothing happens, check these in order.

| Check | What you want |
| --- | --- |
| The second edge | An edge from `false` to `false`. Without it, the LED never switches off. |
| The Button node | Connect a [Monitor](/docs/microflow-studio/nodes/express/monitor) to the `value` output. Pressing the button shows `1`. A constant `0` means the button is wired wrong or on another pin. |
| The sidebar status | A port name. |
| The pin numbers | The pin in each node matches the pin on the board. See [Nothing happens on the board](/docs/troubleshooting/pin-conflicts). |

## What just happened

The Button node watches pin 2 and reports the result on five outputs at once:

- `true` while you hold the button.
- `false` while the button is up.
- `event` on every change.
- `hold` after a long press.
- `value` as `1` or `0`.

You used two of them. The LED node's `true` and `false` inputs are commands: a signal arrives, and the LED does that thing. You wrote no if-then logic.

This is the **sense → express** pattern. Input from the world, output to the world.
