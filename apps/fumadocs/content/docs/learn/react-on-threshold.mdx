Until now every value reached the output. Often that is too much: you want the LED on only when the room is dark enough. That decision belongs to a **Decide** node.

## What you need

The setup from [Fade an LED with a potentiometer](/docs/learn/fade-with-potentiometer): a potentiometer on `A0` and an LED on pin `9`.

<Callout type="info" title="Template available">
Studio ships this flow as the **Threshold Alert** template, under **Templates**.
</Callout>

## Step 1 — Find your threshold

1. Connect a [Monitor](/docs/microflow-studio/nodes/express/monitor) node to the Potentiometer node's `value` output.
2. Turn the knob through its full travel. The value runs from `0` to `1023`.
3. Choose a number in the middle, such as `512`.

## Step 2 — Add a Compare node

1. Add a [Compare](/docs/microflow-studio/nodes/decide/compare) node.
2. Connect the Potentiometer node's `value` output to the Compare node's `value` input.
3. Set **Compare as** to `number`.
4. Set **Test** to `greater than`.
5. Set **Number** to `512`.

## Step 3 — Drive the LED

1. Connect the Compare node's `true` output to the LED node's `true` input.
2. Connect the Compare node's `false` output to the LED node's `false` input.

Turn the knob. The LED stays off below 512 and switches on above it.

Draw both edges. With only the first, the LED switches on and never switches off.

## Step 4 — Try the other tests

Set **Test** to `less than` and the LED inverts. Set it to `equal to` and the LED reacts only at the exact value, which is hard to hit with a knob.

Compare also tests text, odd and even numbers, and whether a number sits inside a range. Set **Compare as** to choose.

## What just happened

The flow now runs **Sense → Decide → Express**. A Decide node does not transform a value the way a Shape node does. It answers a question about the value, and its `true` and `false` outputs drive anything that takes a command.

## If the LED flickers at the boundary

Hold the knob at exactly 512 and the LED flickers. The raw reading crosses the boundary many times a second.

Add a [Smooth](/docs/microflow-studio/nodes/shape/smooth) node before the Compare node. See [Values look wrong](/docs/troubleshooting/values-look-wrong#chatter).
