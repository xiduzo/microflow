Connect any analog sensor to a Monitor node and hold the sensor still. The reading still moves. Every analog input carries some noise. In this lesson you see the noise, then remove it.

## What you need

The setup from [Fade an LED with a potentiometer](/docs/learn/fade-with-potentiometer): a potentiometer on `A0` and an LED on pin `9`.

<Callout type="info" title="Template available">
Studio ships the finished flow as the **Smooth a Noisy Sensor** template, under **Templates**.
</Callout>

## Step 1 — See the noise

1. Add a [Monitor](/docs/microflow-studio/nodes/express/monitor) node.
2. Connect the Potentiometer node's `value` output to it.
3. Set the Monitor's **Type** to `graph`.
4. Hold the knob still and watch the graph.

The value moves by one to three units per reading while you touch nothing. That is sensor noise.

For an LED it does not matter. For a motor speed, a threshold, or a value you send to another tool, it does.

## Step 2 — Add a Smooth node

1. Add a [Smooth](/docs/microflow-studio/nodes/shape/smooth) node between the Potentiometer node and the Map node.
2. Connect Potentiometer → Smooth → Map → LED.
3. Set the Smooth node's **Type** to `moving average`.
4. Set **Window size** to `25`.
5. Add a second Monitor node on the Smooth node's output.

Keep the first Monitor on the Potentiometer node so you can compare the two graphs.

Hold the knob still. The smoothed graph is flat. Turn the knob quickly. The smoothed graph lags behind the raw one.

## Step 3 — Tune it

Smoothing trades noise against speed.

| Setting | Effect |
| --- | --- |
| A larger **Window size** | Less noise, more lag |
| A smaller **Window size** | More noise, faster response |

Try `5`, `25`, and `100`. Watch both graphs, and feel how the LED responds.

The **smooth** type is the alternative. It uses an **Attenuation** between `0` and `1`, where a value closer to `1` smooths harder. It responds faster than a large window, but never settles on the exact value. Start with a moving average.

## What just happened

- A Shape node does not change what a flow does. It changes how the values look on the way through.
- Smoothing has no correct setting, only a choice that suits your project.
- A Monitor node before and after a node shows you exactly what that node does.
