The Microflow Hardware Bridge is a **Figma plugin**. It links the variables in a Figma file to a flow in [Microflow Studio](/docs/microflow-studio). A sensor can change a variable in your design, and a change to a variable can drive your hardware.

**Example:** you turn a potentiometer on your desk, and the width of a rectangle in your Figma file changes with it.

<Callout type="warn" title="The bridge works in the editor, not in prototypes">
Figma runs plugins only in the editor. The bridge links your hardware to the variables of a file that is open in the editor, with the plugin running. It does not reach a running prototype.
</Callout>

---

## How it works

1. You run the plugin in a Figma file. The plugin uses the variables in a collection called **MHB** (Microflow Hardware Bridge). It creates the collection if the file has none.
2. In Studio, a [Design variable](/docs/microflow-studio/nodes/express/figma) node lists those variables. You pick one and connect the node to the rest of your flow.
3. Studio and the plugin send messages to each other through an [MQTT broker](/docs/microflow-hardware-bridge/mqtt). Both must use the same broker and the same **Bridge ID**.

When your flow sends a value into the node, the plugin writes it into the variable. When you change the variable in Figma, the node sends the new value out of its `change` output.

## Install

Install [Microflow Hardware Bridge from the Figma Community](https://www.figma.com/community/plugin/1373258770799080545). Then open a Figma Design file and run the plugin from Figma's plugin menu.

<Callout title="You also need Microflow Studio">
The plugin is one half of the bridge. Set up [Microflow Studio](/docs/microflow-studio) before you continue.
</Callout>

## Set it up

1. In Studio, open **Configuration → MQTT** and add a broker. For a quick start, use the plugin's default broker: `wss://test.mosquitto.org:8081/mqtt`.
2. In your flow, add a **Design variable** node and select that broker. The node shows its Bridge ID. Click **copy bridge ID** in the node settings.
3. In the plugin, click the gear icon to open the MQTT settings. Paste the Bridge ID, keep the default broker URL, and click **Save MQTT settings**.
4. Add a variable to the **MHB** collection. See [Connecting variables](/docs/microflow-hardware-bridge/variables/connecting).
5. In Studio, pick the variable in the node's **variable** setting and connect the node. See [Using variables with Microflow](/docs/microflow-hardware-bridge/variables/manipulating).

The plugin's home screen shows two status dots:

- **MQTT** is green when the plugin is connected to the broker.
- **Microflow studio** is green when a Studio flow with a Design variable node uses the same broker and Bridge ID.

## Limitations

- The bridge works only while the file is open in the editor and the plugin is running.
- The plugin reads and writes the value in each collection's default mode.
- On a public broker, the Bridge ID is the only thing that keeps your values apart from other people's. See [MQTT settings](/docs/microflow-hardware-bridge/mqtt).
