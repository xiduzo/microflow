---
title: Variables
description: How the variables in a Figma file become live values in a Microflow flow.
---

The plugin links the variables in one collection, **MHB**, to Microflow Studio. In Studio, a [Design variable](/docs/microflow-studio/nodes/express/figma) node can read and change each of them. Values go both ways:

- **Hardware → Figma.** A value arrives at one of the node's inputs. The plugin writes it into the variable, and Figma redraws every layer that uses the variable.
- **Figma → hardware.** You change the variable in Figma. The node sends the new value out of its `change` output.

<Callout title="Same broker, same Bridge ID">
Studio and the plugin find each other only when they use the same MQTT broker and the same Bridge ID. See [MQTT settings](/docs/microflow-hardware-bridge/mqtt).
</Callout>
