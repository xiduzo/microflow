title: Connecting variables
description: Put variables in the MHB collection so the plugin links them to Microflow Studio.
---

The plugin links the variables in a collection called **MHB** (short for Microflow Hardware Bridge). When you run the plugin, it creates the collection if the file has none.

**Only variables in the MHB collection are linked.** Variables in other collections stay out of the bridge.

---

## Set it up

1. Run the **Microflow Hardware Bridge** plugin in your Figma file.
2. Open Figma's local variables and select the **MHB** collection.
3. Create variables in the collection, or move existing variables into it.
4. Bind the variables to layers as usual, so you can see them change.
5. In the plugin, click the variables icon on the home screen. The **Variables** page lists every linked variable.

## Supported types

| Figma type | Studio type | Example value |
| --- | --- | --- |
| Boolean | `BOOLEAN` | `true` |
| Number | `FLOAT` | `42.5` |
| String | `STRING` | `Hello` |
| Color | `COLOR` | red, with an alpha |

The plugin skips variables of any other type.

## How the plugin reads a variable

- It reads the value in the collection's **default mode**. Other modes are not linked. When Studio changes a variable, the plugin writes the default mode.
- It follows an alias to the variable it points to, in that variable's own default mode. An MHB variable can point to a variable in another collection.
- A color made from a color and an opacity is sent as one color. The opacity becomes the color's alpha.

When Studio writes a value into a variable that holds an alias, the plain value replaces the alias.

## Renaming and deleting

Studio links to a variable by its Figma ID, not by its name. You can rename a variable, and it stays linked. If you delete a variable and create a new one with the same name, pick the new one again in Studio.
