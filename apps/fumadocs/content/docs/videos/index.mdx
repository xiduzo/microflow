The docs carry two kinds of moving image.

- **Videos** — narrated walkthroughs, two to six minutes. Fourteen of them, listed below, each with a finished shooting script and a transcript.
- **Clips** — short, silent, looping demonstrations of one behaviour. Fifty-five of them, specified on the [clip sheet](/docs/videos/clips) and grouped by the rig you build to shoot them.

Every one has a finished spec. Anyone with the hardware on their desk can record them.

<Callout type="warn" title="None of these are recorded yet">
The scripts are final. The recordings are not. Every slot in the docs shows a **TODO** placeholder until a recording exists.

To publish one, add its embed URL as the `src` of the `<Video />` tag on every page listed under **Where it appears** in its script. Nothing else changes.
</Callout>

## Everything stays readable as text

No video in these docs carries information that the page does not already state in writing.

Each narrated video has a **transcript** on its script page: every spoken word, in order, with timecodes. Each clip has a caption saying what it shows. Both are in the page markup, so search, screen readers, and anything reading the docs as text get the same content as a viewer.
