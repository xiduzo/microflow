## Script

### 0:00 — The three regions

**Screen:** The full window with the `Tour` flow running.

**Narration:**
> "Three regions. The sidebar on the left is everything about your flow. The canvas in the middle is the flow. The dock along the bottom is what you do to the canvas."

**On-screen:** Dim the window and light each region as it is named.

### 0:35 — The sidebar

**Screen:** The sidebar alone, cursor moving down it.

**Narration:**
> "At the top, the flow switcher: every flow you have, and the button to make a new one. Below it, the microcontroller status. Right now it shows the port my board is on. When nothing is plugged in it says so, and the question mark opens the troubleshooting page.
>
> Under that, the current flow and its three views: Edit flow, Show circuit, Show code. Then the general section: My flows, Templates, and Configuration, where MQTT brokers and AI providers live. You set those once, and every flow uses them."

**On-screen text:** `Flow switcher` · `Board status` · `Edit / Circuit / Code` · `My flows · Templates · Configuration`

### 1:40 — The canvas

**Screen:** Drag empty canvas to pan. Scroll to zoom. Drag a box across two nodes. Drag inside the minimap.

**Narration:**
> "Drag empty space to pan. Scroll to zoom. Drag across nodes to select several. Shift and one fits everything in view, or just what you have selected, which is the version you will use. The minimap in the corner is draggable too."

**On-screen text:** `Shift + 1 — zoom to fit`

### 2:25 — The dock

**Screen:** The dock. Hover each icon, and click the safe ones.

**Narration:**
> "Left to right: add a node, undo, redo, export this flow to a file, and the flow's settings. Undo and redo go dim when there is nothing left to undo. Export writes the flow to a file you can send to someone. Settings is where you rename the flow, invite collaborators, and delete it."

### 3:05 — A node up close

**Screen:** Zoom to 200 % on the Smooth node. Point at the inputs, then the output. Click the node to open its settings. Change the window size and watch the value change.

**Narration:**
> "Every node is the same three things. Inputs on the left. Outputs on the right. Settings when you click it. The number on the node is its current value, updating live, so you can watch a value move through your flow and see where it stops making sense."

### 3:45 — Three views of one flow

**Screen:** Click **Show circuit**. Hold on the diagram. Then **Show code**, scroll the sketch, and hover **Download sketch** without clicking. Return to **Edit flow**.

**Narration:**
> "The same flow, three ways. Circuit shows you how to wire the components you used, pin by pin. Code shows the Arduino sketch your flow compiles to, and you can download it as a dot-ino file. That is your escape hatch: whatever you build here, you can take with you."

**On-screen text:** `Show circuit · Show code · Download sketch`

### 4:30 — Six shortcuts

**Screen:** A card listing the six, each performed on the canvas as it appears.

**Narration:**
> "Six worth learning. Command K adds a node. Command C and Command V copy and paste, and the paste lands at your cursor. Command Z and Command Shift Z undo and redo. Shift one fits the view. Command and a number switches flows. Everything else you can find with the mouse."

**On-screen text:**
```
Cmd/Ctrl + K      add node
Cmd/Ctrl + C / V  copy / paste at cursor
Cmd/Ctrl + Z      undo   ·  + Shift  redo
Shift + 1         zoom to fit (selection first)
Cmd/Ctrl + 1…9    switch flow
```

## Deliberate failure

None. The failures live in the videos that build something.

## Post-production notes

- Keep the region-lighting effect at 0:00. It sets up the whole video.
- Clear the downloads bar before the take. Do not click **Download sketch** on camera.
- Perform every shortcut you name. Caption each keystroke as `[Cmd+K]`.
