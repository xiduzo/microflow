## Script

### 0:00 — The three regions

**Screen:** Full window, the `Tour` flow open, values moving.

**Narration:**
> "Three regions. The sidebar on the left is everything *about* your flow. The canvas in the middle is the flow itself. The dock along the bottom is what you do *to* the canvas. That is the whole interface."

**On-screen:** Dim the window and light each region as it is named.

### 0:35 — The sidebar

**Screen:** Sidebar only, cursor moving down it as each item is named.

**Narration:**
> "At the top is the flow switcher — every flow you have, and the button to make a new one. Below it, the microcontroller status. Right now it shows the port my board is on; when nothing is plugged in it says so, and the question mark beside it opens the troubleshooting page.
>
> Under that, the current flow with its three views: Edit flow, Show circuit, Show code. Then the general section: My flows, Templates, and Configuration — which is where MQTT brokers and AI providers live. Those are set up once and shared by every flow."

**On-screen text, as each is named:** `Flow switcher` · `Board status` · `Edit / Circuit / Code` · `My flows · Templates · Configuration`

### 1:40 — The canvas

**Screen:** Drag on empty canvas to pan. Scroll to zoom. Drag a selection box across two nodes. Point at the minimap in the corner and drag inside it.

**Narration:**
> "Drag empty space to pan. Scroll to zoom. Drag across nodes to select several at once. When you lose yourself, Shift and one zooms to fit — or to fit just the nodes you have selected, which is the version you will actually use. The minimap in the corner is draggable too."

**On-screen text:** `Shift + 1 — zoom to fit`

### 2:25 — The dock

**Screen:** Bottom-centre dock. Hover each icon slowly; click the ones that are safe to demonstrate.

**Narration:**
> "Left to right: add a node, undo, redo, export this flow to a file, and the flow's settings. Undo and redo go dim when there is nothing left to undo — which is a quicker way to tell than trying it. Export writes the flow to a file you can send to someone else. Settings is where you rename the flow, invite collaborators, and delete it."

### 3:05 — A node up close

**Screen:** Zoom to 200 % on the Smooth node. Point at the input handles on the left, output on the right. Click the node to open its settings. Change the smoothing amount and watch the live value change behaviour.

**Narration:**
> "Every node is the same three things. Inputs on the left. Outputs on the right. Settings when you click it. The number on the node is its current value, updating live while the flow runs — which means you can watch a value move through your flow and see exactly where it stops making sense."

### 3:45 — Three views of one flow

**Screen:** Click **Show circuit**. Hold on the generated wiring diagram. Then **Show code**, scroll the generated Arduino sketch, and hover the **Download sketch** button without clicking. Return to **Edit flow**.

**Narration:**
> "The same flow, three ways. Circuit shows you how to wire the components you have used — pin by pin, so you can build the physical side from it. Code shows the Arduino sketch your flow compiles to, and you can download it as a dot-ino file and open it in the Arduino IDE. That is your escape hatch: whatever you build here, you can take with you."

**On-screen text:** `Show circuit · Show code · Download sketch`

### 4:30 — Shortcuts worth memorising

**Screen:** Card listing six shortcuts, demonstrating each on the canvas as it appears.

**Narration:**
> "Six worth learning. Command K adds a node. Command C and Command V copy and paste — the paste lands wherever your cursor is. Command Z and Command Shift Z undo and redo. Shift one fits the view. Command and the number one, two, three switches between your flows. Everything else you can find with the mouse."

**On-screen text:**
```
Cmd/Ctrl + K      add node
Cmd/Ctrl + C / V  copy / paste at cursor
Cmd/Ctrl + Z      undo   ·  + Shift  redo
Shift + 1         zoom to fit (selection first)
Cmd/Ctrl + 1…9    switch flow
```

## Deliberate failure

None here — the tour has no task to fail. The failure content lives in the videos that build something.

## Post-production notes

- The region-lighting effect at 0:00 sets up the whole video; do not skip it to save time.
- Do not click **Download sketch** on camera unless you have cleared your download bar. A downloads popup mid-shot is the usual reshoot.
- Every shortcut named must be visibly performed. Captions carry the keystroke as `[Cmd+K]`.
