<Callout type="info" title="macOS vs. Windows and Linux">
`Cmd` on macOS is `Ctrl` on Windows and Linux. Where this page writes `Cmd/Ctrl`, use whichever your platform expects.
</Callout>

## Canvas

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl + K` | Open the **Add node** palette |
| `Cmd/Ctrl + =` | Zoom in |
| `Cmd/Ctrl + -` | Zoom out |
| `Cmd/Ctrl + 0` | Zoom to 100 % |
| `Shift + 1` | Zoom to fit — the selected nodes if any are selected, otherwise the whole flow |
| Drag empty canvas | Pan |
| Scroll | Zoom |

## Editing

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl + C` | Copy the selected nodes |
| `Cmd/Ctrl + V` | Paste — the nodes land where your mouse pointer is, not where they were copied from |
| `Cmd/Ctrl + A` | Select every node and edge |
| `Cmd/Ctrl + Z` | Undo |
| `Cmd/Ctrl + Shift + Z` | Redo |
| `Delete` / `Backspace` | Delete the selection |

## Flows

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl + 1` … `9` | Switch to the first, second, … ninth flow in the flow switcher |

## Mouse

| Action | Result |
| --- | --- |
| Click a node | Select it and open its settings |
| Shift + drag on empty canvas | Select everything inside the box |
| Drag handle to handle | Draw an edge |
| Click an edge | Select it |

## Notes

- A shortcut that would type a character is ignored while you are in a text field. In a Function node's editor, `Cmd/Ctrl + A` selects the text, not every node on the canvas.
- A [Hotkey node](/docs/microflow-studio/nodes/sense/hotkey) claims a plain letter or digit key for your flow. Those fire only when Studio has focus and you are not typing in a field.
- In a flow you are viewing rather than editing, editing shortcuts and the delete key do nothing. See [Collaborate on a flow](/docs/how-to/collaborate-on-a-flow).
