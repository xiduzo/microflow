title: Microflow Studio
description: The app where you build interactive hardware projects on a visual canvas.
---

You build in Studio. Drag [nodes](/docs/microflow-studio/nodes) onto a canvas, connect them with [edges](/docs/microflow-studio/edges), and Studio runs the result on your board over USB. There is no compile step and no run button. Edit the canvas while the flow runs, and the change applies at once.

Studio comes in two forms that do the same thing:

- **The desktop app**, for Windows, macOS, and Linux. It finds your board on its own, and it is the only form that configures MQTT brokers and AI providers. [Download it](https://github.com/xiduzo/microflow-t-stack/releases).
- **The web app**, in Chrome, Edge, or Opera, with nothing to install. See [Use Studio in your browser](/docs/how-to/use-studio-in-your-browser).

Start with [Learn](/docs/learn). If your board is already on the desk, [connect it first](/docs/how-to/connect-a-microcontroller).

## The window

### The sidebar

Everything about your flow, top to bottom:

- **Flow switcher** — every flow you have, and the button to create one. `Cmd/Ctrl + 1` to `9` switches between them.
- **Microcontroller status** — which board is connected, or why none is. The question mark opens [Board not detected](/docs/troubleshooting/board-not-detected).
- **The current flow** — its three views: **Edit flow**, **Show circuit**, and **Show code**.
- **General** — **My flows**, **Templates**, and **Configuration** for [MQTT brokers](/docs/how-to/run-your-own-mqtt-broker) and [AI providers](/docs/how-to/connect-a-local-llm). You set those once, and every flow uses them.

### The canvas

- **Add a node** — press `Cmd/Ctrl + K`, or click `+` in the dock. Search the palette by what the node does, not only by its name.
- **Connect nodes** — drag from a handle on the right of one node to a handle on the left of another.
- **Move a node** — drag it. **Pan** — drag the empty canvas. **Zoom** — scroll.
- **Fit the view** — press `Shift + 1`. With nodes selected, it fits the selection.

Each node shows its live value while the flow runs. See [Debug with the Monitor node](/docs/how-to/debug-with-monitor-node).

### The dock

Along the bottom: **add node**, **undo**, **redo**, **export this flow to a file**, and **flow settings**. Undo and redo dim when there is nothing left to do. Flow settings is where you rename a flow, [invite collaborators](/docs/how-to/collaborate-on-a-flow), and delete it.

## Three views of one flow

| View | Use it to |
| --- | --- |
| **Edit flow** | Build the flow. |
| **Show circuit** | Read the wiring your flow implies, pin by pin. See [Read the circuit view](/docs/how-to/read-the-circuit-view). |
| **Show code** | Read and download the Arduino sketch your flow compiles to. See [Export an Arduino sketch](/docs/how-to/export-an-arduino-sketch). |

Studio generates the circuit and the code from the flow each time you open the view, so neither can fall out of date.
