---
title: Generate
description: Generate nodes produce values, signals, and events to feed into your flow.
---

Generate nodes create data for the rest of your flow to work with. Unlike Sense nodes, they do not read from physical hardware — they produce values internally, based on time, patterns, or fixed settings.

Use them to:

- Feed a constant number into a calculation
- Create a repeating signal that drives a timer or animation
- Keep a running count of how many times something happened

| Node | What it does |
| --- | --- |
| [Constant](/docs/microflow-studio/nodes/generate/constant) | A fixed number that never changes |
| [Counter](/docs/microflow-studio/nodes/generate/counter) | Counts up, down, and resets |
| [Interval](/docs/microflow-studio/nodes/generate/interval) | Ticks at a regular interval, like a clock |
| [Oscillator](/docs/microflow-studio/nodes/generate/oscillator) | Produces a repeating wave — sine, square, triangle, sawtooth |
