---
title: Oscillator
description: Create a repeating wave-like pattern of numbers that goes up and down.
---

An Oscillator generates a continuously changing number that rises and falls over time. Where a sensor only fires when something in the physical world changes, an Oscillator produces its own changing values driven purely by time. It sends a new value about 60 times per second.

**Waveforms:**
- **sinus** — a smooth, curved wave (like ocean waves). Good for slow, natural-feeling transitions
- **square** — a sharp on/off pattern that toggles between two values. Good for blinking or pulsing at a fixed rate
- **triangle** — a straight-line up and down pattern. Similar to sinus but with sharper turning points
- **sawtooth** — a gradual rise followed by a sudden drop. Good for one-directional sweeps that reset
- **random** — a new random number on every value
- **randomwalk** — a random number that glides to a new random number once per period
- **perlin** — a smooth random drift, without the corners of randomwalk

**Examples:**
- Create a pulsing LED that smoothly fades in and out using a sinus wave
- Blink an LED at a precise rate using a square wave
- Make a servo motor sweep back and forth automatically
- Animate a variable in a Figma or Penpot file through the [Design variable](/docs/microflow-studio/nodes/express/figma) node

## Inputs

- **start** — starts the wave
- **reset** — starts the wave again from the beginning, if it is running
- **stop** — stops the wave

## Outputs

- **value** — the current value of the wave

## Settings

Open the settings panel to configure:

- **waveform** — the shape of the pattern (see above). The default is sinus
- **period (ms)** — how long one full cycle takes, in milliseconds. 1000 ms = one cycle per second. The default is 1000 ms and the lowest is 100 ms
- **amplitude** — how large the swings are. With an amplitude of 100, sinus, square, triangle and sawtooth travel from −100 to +100. The default is 1
- **phase** — where in the cycle the wave starts, in milliseconds. Leave this at 0 for most uses
- **shift** — a number added to every value, to move the wave up or down. With an amplitude of 100 and a shift of 100, the wave travels from 0 to 200. The random waveforms give numbers from 0 up to amplitude plus shift
- **auto start** — when on (the default), the wave starts as soon as the flow runs
