title: Constant
description: Provide a fixed number that never changes to use throughout your flow.
---

A Constant node provides a fixed number that never changes. Think of it as a number you set once and it stays the same.

**Examples:**
- Set a constant value of 100 to use as a threshold for comparisons
- Use a constant value of 5 to multiply sensor readings by
- Provide a fixed brightness level (like 128) for an LED

Use a Constant when your flow needs a fixed number that comes from no sensor and never changes. You can combine it with the [`Calculate`](/docs/microflow-studio/nodes/shape/calculate) node to do math — for example, multiply a sensor reading by your constant value.

## Inputs

This node has no inputs. It produces values on its own.

## Outputs

- **`value`** — The fixed number, sent once when the flow starts and whenever you change it.

## Settings

- **Value** — The number this node sends. Default `1337`.
