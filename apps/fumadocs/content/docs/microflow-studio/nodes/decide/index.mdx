---
title: Decide
description: Decide nodes add logic to your flow — comparisons, counting, delays, and gates.
---

A Decide node controls what happens and when. It reads no sensor and drives no output. It tests, combines, and delays the values passing through.

Use one to:

- Check whether a value is above a threshold
- React only when a value changes sharply
- Wait a moment before passing a signal through
- Combine conditions with AND, OR, and other logic

| Node | What it does |
| --- | --- |
| [Compare](/docs/microflow-studio/nodes/decide/compare) | Tests a value and answers true or false |
| [Gate](/docs/microflow-studio/nodes/decide/gate) | Combines several signals with AND, OR, XOR, NAND, NOR, XNOR |
| [Trigger](/docs/microflow-studio/nodes/decide/trigger) | Fires when a value changes by more than a threshold |
| [Delay](/docs/microflow-studio/nodes/decide/delay) | Holds a signal before passing it on — and debounces |
