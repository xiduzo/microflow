---
title: Counter
description: Keep track of how many times something happens.
---

The Counter node keeps a running total. Each time it receives a signal, it adds or subtracts 1 and outputs the new total. You can also reset it, or jump it to a specific value at any time.

**Examples:**
- Count how many times a button has been pressed
- Track how many times a sensor detects movement
- Count down from 10 and trigger something when it reaches zero
- Keep score in an interactive game

## Inputs

- **+** (increment) — adds 1 to the count
- **set** — sets the count to the incoming number
- **-** (decrement) — subtracts 1 from the count
- **reset** — sets the count back to 0

## Outputs

- **value** — the count, each time it changes

## Settings

The Counter node has no settings. The count starts at 0.
