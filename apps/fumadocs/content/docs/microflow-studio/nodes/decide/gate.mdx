title: Gate
description: Apply logic gates (AND, OR, etc.) to make decisions based on several inputs.

A logic gate is a way to make decisions based on several inputs. Think of it like a simple rule that checks conditions and gives you a result.

For example, an AND gate is like saying "all things must be true" - like "it's daytime AND the lights are off" before turning on a light. An OR gate is like saying "any thing can be true" - like "if it's dark OR someone presses a button, turn on the light."

Connect as many edges as you need to the gate's one input. The gate reads each connected value as true or false and produces a single result. Here is a plain-English summary of each gate:

| Gate | What it means |
| --- | --- |
| **and** | All inputs must be true → output is true |
| **nand** | Opposite of AND — output is false only when all inputs are true |
| **or** | At least one input must be true → output is true |
| **nor** | Opposite of OR — output is true only when all inputs are false |
| **xor** | Exactly one input must be true → output is true |
| **xnor** | Opposite of XOR — output is true unless exactly one input is true |

## Inputs

- **value** — connect every value the gate should combine to this one input

## Outputs

- **true** — fires when the result is true
- **false** — fires when the result is false

The gate checks each time a value arrives, and one of the two outputs fires every time, even when the result is the same as before. Studio and the exported Arduino sketch behave the same way.

## Settings

Open the settings panel to configure:

- **gate** — which logical operation to apply: and (the default), nand, or, nor, xor, xnor
