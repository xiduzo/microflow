title: Compare
description: Check if values meet a condition and route your flow based on true or false results.
---

The Compare node checks whether a value meets a condition — greater than, less than, equal to, and so on. Based on whether the check passes or fails, it routes a signal down one of two paths.

<Clip title="Compare" duration="0:20" spec="compare">
The LED switches on above 512 and off below it.
</Clip>

**Example:** If a temperature sensor reads above 80°C, send a signal to turn on a fan. Otherwise, send a signal to keep the fan off.

The Compare node re-tests every incoming value, so its outputs describe the value you have right now. If you care about a sudden change instead — a light dropping fast, a knock, a hand passing over — use the [Trigger](/docs/microflow-studio/nodes/decide/trigger) node. It watches the rate of change.

## Inputs

- **`value`** — The value to test.

## Outputs

- **`true`** — True while the comparison passes.
- **`false`** — True while the comparison fails.
- **`value`** — The result as a value — `1` when the comparison passes, `0` when it fails.

## Settings

- **Compare as** — What kind of comparison to make. Default `boolean`.
- **Test** — The specific test within that kind. Default `true`.
- **Text** — The text to compare against.
- **Number** — The number to compare against. Default `0`.
