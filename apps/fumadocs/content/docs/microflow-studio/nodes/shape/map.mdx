The Map node converts a number from one range to another range. This is useful when you need to translate values between different scales.

**Simple example:** Imagine you have a sensor that gives you values between 0 and 100, but you need values between 0 and 10 for an LED brightness. The Map node converts 50 (which is in the middle of 0-100) to 5 (which is in the middle of 0-10).

<Callout type="info" title="Image placeholder">
  Diagram illustrating a simple value mapping from input range 0–100 to output range 0–10, showing how the midpoint value 50 maps to 5.
</Callout>

**Real-world use:** A light sensor might read values from 0 to 1023, but you want to control an LED brightness from 0 to 255. The Map node automatically converts any sensor reading to the correct brightness value.

You can map any input range to any output range - they don't have to match. For example, you could convert values from 30-80 to 28-115, or any other ranges you need.

<Callout type="info" title="Image placeholder">
  Diagram illustrating a complex value mapping from input range 30–80 to output range 28–115, demonstrating that input and output ranges do not need to align or overlap.
</Callout>

The output range can be completely different from the input range - it doesn't have to overlap at all.

## Inputs

- **`value`** — The value to rescale.

## Outputs

- **`to`** — The rescaled value. This is the output you normally use.
- **`value`** — The unscaled value that came in, passed through.

## Settings

- **From** — The range the incoming value lives in, as a **min** and a **max**. Default `0`–`1023`, which is what an analog pin gives you.
- **To** — The range to rescale it into, as a **min** and a **max**. Default `0`–`1023`.

Values outside the **From** range are still scaled, so they land outside the **To** range too. Clamp them with a [Compare](/docs/microflow-studio/nodes/decide/compare) node first if that matters.
