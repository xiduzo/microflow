---
title: Shape
description: Shape nodes transform and process data as it flows through your project.
---

A Shape node sits in the middle of a flow and changes the values passing through it. It reads no hardware and drives no output.

Use one to:

- Do maths on a sensor reading.
- Rescale a value from one range into another, such as `0`–`1023` into `0`–`255`.
- Smooth a noisy reading.

| Node | What it does |
| --- | --- |
| [Calculate](/docs/microflow-studio/nodes/shape/calculate) | Adds, subtracts, multiplies, and divides |
| [Function](/docs/microflow-studio/nodes/shape/function) | Runs your own JavaScript on the values passing through |
| [Map](/docs/microflow-studio/nodes/shape/map) | Rescales a number from one range into another |
| [Smooth](/docs/microflow-studio/nodes/shape/smooth) | Averages recent readings to kill sensor noise |
