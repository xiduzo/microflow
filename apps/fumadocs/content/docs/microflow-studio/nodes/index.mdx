A node does one thing: it reads a sensor, drives a light, does maths, or makes a decision. You connect nodes with [edges](/docs/microflow-studio/edges), and values travel along the edges from one node to the next.

For example: an LDR node reads the room's brightness, a Map node rescales the reading, and an LED node matches it.

Every node is documented here with the same input, output, and setting names that appear on the node itself.

## Adding a node to the canvas

1. Press `Cmd/Ctrl + K`, or click `+` in the dock, to open the **Add node** palette.
2. Type what you want. The palette searches each node's description and tags as well as its name, so `distance`, `noise`, and `magnet` all find the right node.
3. Press Enter to place the node.

Then:

- **Move a node** — drag it.
- **Configure a node** — click it.
- **Copy and paste a node** — `Cmd/Ctrl + C`, then `Cmd/Ctrl + V`. The copy lands at the pointer.
- **Delete a node** — select it and press Delete or Backspace.

## Anatomy of a node

Every node has inputs on the left, outputs on the right, and settings that open when you click it.

The number or icon in the middle is the node's live value. It updates while the flow runs, so you can follow a value through the flow and find the point where it stops making sense.

### Handle shapes

Handles are drawn as one of four symbols, and the symbol tells you what the handle carries:

| Symbol | Kind | What it carries |
| --- | --- | --- |
| ● | Value | A number, colour, or text that updates continuously |
| ◆ | Event | A moment — fires and is gone |
| ■ | State | A condition that is true or false right now |
| ▶ | Command | An instruction: turn on, reset, play, send |

Some handles carry a hint beside them, such as `0-255` or `requires a ~ pin`. The hint states what the node expects. A handle that refuses to connect has an unmet requirement.

See [Edges](/docs/microflow-studio/edges) for which kinds pair well.
