Nodes are the building blocks of a flow. Each node does one specific thing — reading a sensor, turning on a light, doing math, making a decision — and you connect them together to build something interactive.

You connect nodes using [edges](/docs/microflow-studio/edges) (the lines between them). Data and signals travel along these edges from one node to the next.

**Example:** an LDR reads the room's brightness → a Map node rescales the reading → an LED matches it.

Every node in Studio is documented here with its exact inputs, outputs, and settings — the same names you see on the node itself.

## Adding a node to the canvas

Press `Cmd/Ctrl + K`, or click the `+` in the dock at the bottom, to open the **Add node** palette. It is grouped by category and searchable — and it searches each node's description and tags as well as its name, so typing `distance`, `noise`, or `magnet` finds the right node without knowing what it is called.

Press Enter to place the highlighted node on the canvas.

Once a node is there:

- **Move it** by dragging.
- **Configure it** by clicking it.
- **Copy and paste it** with `Cmd/Ctrl + C` and `Cmd/Ctrl + V` — it lands where your pointer is.
- **Delete it** by selecting it and pressing Delete or Backspace.

## Anatomy of a node

Every node is the same three things.

**Inputs** on the left. **Outputs** on the right. **Settings** when you click it.

The number or icon in the middle of a node is its **live value**, updating while the flow runs. That is the fastest debugging tool in Studio: you can watch a value travel through your flow and see exactly where it stops making sense.

### Handle shapes

Handles are drawn as one of four symbols, and the symbol tells you what the handle carries:

| Symbol | Kind | What it carries |
| --- | --- | --- |
| ● | Value | A number, colour, or text that updates continuously |
| ◆ | Event | A moment — fires and is gone |
| ■ | State | A condition that is true or false right now |
| ▶ | Command | An instruction: turn on, reset, play, send |

Some handles also carry a hint next to them — `0-255`, `requires a ~ pin` — which tells you what the node expects before you connect anything. A handle that refuses to connect is usually one whose requirement is not met.

See [Edges](/docs/microflow-studio/edges) for which kinds pair well.
