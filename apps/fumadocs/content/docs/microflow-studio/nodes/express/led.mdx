An LED (Light Emitting Diode) is a small light that turns on when electricity flows through it. This page covers three nodes: the **LED** node for a single-color LED, the **RGB** node for an RGB LED, and the **LED Matrix** node for a grid of LEDs.

**Example uses:**
- Turn on a light when a button is pressed
- Gradually dim a light based on a sensor reading
- Show status using different colors with an RGB LED
- Display patterns or animations on a grid of LEDs

---

## LED

A single LED can be switched on and off, or have its brightness controlled.

### Inputs

- **true** — turns the LED fully on
- **toggle** — switches between on and off
- **brightness** — a number from 0 to 255 that sets brightness. 0 = off, 255 = full brightness. Values in between dim the LED
- **false** — turns the LED fully off

### Outputs

- **value** — the LED's brightness, from 0 (off) to 1 (full)

### Settings

- **pin** — which pin on your Arduino the LED is connected to. The default is pin 13, the built-in LED

<Callout title="Brightness requires a PWM pin">
Dimming an LED (sending values between 0 and 255) requires a PWM-capable pin. On an Arduino Uno, PWM pins are marked with a tilde (~): pins **3, 5, 6, 9, 10, and 11**.

On a pin without PWM, the LED is on for a brightness of 128 or more and off below that, like Arduino's `analogWrite`. On a PWM pin any brightness above 0 lights it. Studio and the exported Arduino sketch use the same rule.
</Callout>

## RGB

An RGB LED packs three LEDs — red, green, and blue — into a single component. Mixing the brightness of each channel produces any color.

**Color mixing reference:**
- Red 255 + Green 255 + Blue 0 = yellow
- Red 255 + Green 0 + Blue 255 = magenta
- Red 0 + Green 255 + Blue 255 = cyan
- All three at 255 = white
- All three at 0 = off

### Inputs

- **red** — brightness of the red channel (0–255)
- **green** — brightness of the green channel (0–255)
- **blue** — brightness of the blue channel (0–255)
- **alpha** — overall brightness, from 0 to 100
- **off** — turns all channels off

### Outputs

- **value** — the current color

### Settings

- **red**, **green**, **blue** *(pins)* — which PWM-capable pins each color channel is connected to. The defaults are pins 9, 10 and 11
- **anode** — turn on for a common-anode RGB LED, where the long leg goes to 5V instead of GND

## LED Matrix

An LED matrix is a grid of individual LEDs driven by a MAX7219 chip — typically 8×8 (64 LEDs total). You can display patterns, icons, or simple frame-by-frame animations.

You draw shapes in the built-in editor in Microflow. To display a specific shape, send its number to the **value** input.

### Inputs

- **value** — which shape to display, as a number (0 for the first shape, 1 for the second, and so on)
- **reset** — clears the display
- **reinitialize** — sets the display up again, for example after it shows garbage

### Outputs

- **value** — the shape on the display

### Settings

- **dimensions** — 8x8 (the default), 16x8, or 8x16
- **devices** — how many matrix modules are chained together (1–8)
- **data (DIN)**, **clock (CLK)**, **chip select (CS)** *(pins)* — the pins the matrix is connected to. The defaults are pins 2, 3 and 4
- **edit shapes** — opens the editor to draw the shapes

The display brightness is fixed.

<Callout title="Shapes start at 0, not 1">
The first shape is shape 0, the second is shape 1, and so on. This is standard in programming — just remember to count from zero when sending values to the value input.
</Callout>
