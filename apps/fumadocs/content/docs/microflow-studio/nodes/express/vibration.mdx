---
title: Vibration
description: Provide haptic feedback using a vibration motor with analog or digital control.
---

A vibration motor makes your project physically shake or buzz — the same kind of feeling as a phone vibrating. This is useful for giving physical feedback to a person without using sound or light.

**Example uses:**
- Vibrate when a button is pressed to confirm an action
- Give a buzz alert when a sensor detects something
- Create a wearable that vibrates in response to events

## Inputs

- **true** — turns the motor fully on
- **toggle** — switches between on and off
- **intensity** — a number from 0 to 255 that sets how strong the vibration is. 0 = no vibration, 255 = full intensity
- **false** — turns the motor off

## Outputs

- **value** — the motor's intensity, from 0 (off) to 1 (full)

## Intensity control

If the vibration motor is connected to a **PWM pin**, the **intensity** input controls how strong the vibration is.

On a pin without PWM, the motor is simply on or off: on for an intensity of 128 or more, off below that.

## Settings

Open the settings panel to configure:

- **pin** — which pin on your Arduino the vibration motor is connected to. Use a PWM-capable pin if you want to control intensity.
