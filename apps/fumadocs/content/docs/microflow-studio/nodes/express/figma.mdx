The Figma node binds to one variable in a Figma file. Your flow can write the variable, read it, or both. The [Hardware Bridge](/docs/microflow-hardware-bridge) plugin does the Figma half.

The variable follows the knob. Changing it in Figma sends a value back the other way.
</Clip>

The node also works with the [Penpot plugin](/docs/microflow-penpot-plugin), which answers the same requests with its design tokens.

Studio and the design tool never talk directly. A plugin cannot reach a USB port, so both ends pass messages through an MQTT broker.

## Inputs

- **`true`** — Set a boolean variable to true.
- **`false`** — Set it to false.
- **`toggle`** — Flip a boolean variable.
- **`set`** — Set the variable to the value that arrives here.
- **`increment`** — Add one to a number variable.
- **`decrement`** — Subtract one.
- **`reset`** — Return the variable to its initial value.
- **`red`** — Red channel of a colour variable, `0`–`255`.
- **`green`** — Green channel, `0`–`255`.
- **`blue`** — Blue channel, `0`–`255`.
- **`opacity`** — Opacity of a colour variable, `0`–`100`.

## Outputs

- **`change`** — Fires when the variable changes in Figma.
- **`value`** — The variable's current value in Figma.

The handles follow the variable's type. A boolean variable shows `true`, `false`, and `toggle`. A number shows `set`, `increment`, `decrement`, and `reset`. A colour shows the four channel inputs. A string shows `set`.

## Settings

- **Broker** — Which configured MQTT broker to use. Add brokers under **Configuration → MQTT**.
- **Unique identifier** — The identifier that must match the plugin's. Case sensitive.
- **Variable** — Which variable this node is bound to. Studio reads the list from the plugin.
- **Variable type** — The variable's type. Studio sets it when you pick the variable.
- **Debounce time** — The minimum milliseconds between updates sent to Figma. Default `100`.

## Setup

1. Install and run the [Microflow Hardware Bridge plugin](https://www.figma.com/community/plugin/1373258770799080545) in your Figma file. It creates the **MHB** variable collection on its first run, and reads no other collection.
2. Create a variable in the MHB collection. See [Connecting variables](/docs/microflow-hardware-bridge/variables/connecting).
3. Add a Figma node in Studio.
4. Select the broker, and enter the identifier the plugin uses.
5. Select the variable from the **Variable** list.

Broker configuration is available in the desktop app only.

## Tips

- **An empty Variable list means the plugin is unreachable.** Check the identifier at both ends, and check the plugin panel is open.
- **Renaming a variable in Figma is safe.** The node binds to the variable's ID, not its name. Deleting and recreating a variable breaks the binding.
- **Raise Debounce time if Figma struggles.** For a jittery sensor, add a [Smooth](/docs/microflow-studio/nodes/shape/smooth) node before this one instead.
