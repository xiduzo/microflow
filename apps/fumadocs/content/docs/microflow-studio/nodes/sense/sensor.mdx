If your sensor does not have its own dedicated node in Microflow, you can still use it with the generic **Analog Sensor** node, as long as it is an **analog** sensor.

## Analog sensors

An **analog sensor** outputs a continuous range of numbers. These sensors measure a quantity that can vary smoothly. Example: a soil moisture sensor that reads anywhere from dry to saturated.

The node outputs a number from **0 to 1023**. If you are unsure which type your sensor is, check its datasheet or packaging. A sensor that connects to one of the A0–A5 pins is almost certainly analog.

A **digital sensor** outputs one of two states: on or off, detected or not detected. The Analog Sensor node does not read those. For a sensor that only switches a digital pin on and off, use the [Switch](/docs/microflow-studio/nodes/sense/switch) node.

## Outputs

- **value** — the reading, from 0 to 1023

## Settings

Open the settings panel to configure:

- **pin** — which analog pin on your Arduino the sensor is connected to
- **threshold** *(advanced)* — the node sends a new value only when the reading has changed by at least this much since the last value it sent. The default is 1

## When to use this node

Use the Analog Sensor node for sensors that do not have a dedicated page in the documentation, such as:

- Flex resistors (bend sensors)
- Soil moisture sensors
- Rain or water level sensors
- Any other standard analog sensor

For sensors that have their own dedicated node — [Button](/docs/microflow-studio/nodes/sense/button), [LDR](/docs/microflow-studio/nodes/sense/ldr), [Force](/docs/microflow-studio/nodes/sense/force), [Hall Effect](/docs/microflow-studio/nodes/sense/hall-effect), [Tilt](/docs/microflow-studio/nodes/sense/tilt), [Potentiometer](/docs/microflow-studio/nodes/sense/potentiometer), and others — use the specific node instead. Dedicated nodes include settings and context specific to that sensor type.
