A tilt sensor detects whether an object is tilted or upright. It gives you a simple yes/no answer: either the object is in its normal position, or it has been tilted past a certain angle.

The value flips between 0 and 1 as the sensor passes upright.
</Clip>

**Example uses:**
- Detect when a box or container has been knocked over
- Trigger an alert when something should stay upright but gets tilted
- Use the orientation of an object as an on/off switch in your project

## Output values

The Tilt node outputs one of two states:
- **Up** — the sensor is in its normal, upright position
- **Down** (or tilted) — the sensor has been tilted

## Inputs

- **`read`** — Take a reading now. The node also reads on its own schedule, so you only need this if you want readings on your terms.

## Outputs

- **`value`** — `0` or `1` depending on which way the sensor is tipped.

## Settings

- **Pin** — Which pin the component is connected to. Default `A0`.
- **Type** — Which mode the node runs in. Default `analog`.
- **Read frequency** — How often the node reads, in milliseconds. Default `25`.
- **Threshold** — How much the reading must change before the node reports it. Default `1`.
