A Light Dependent Resistor (LDR) — also called a photoresistor — is a small sensor that changes its readings based on how much light hits it. The darker it is, the lower the value. The brighter it is, the higher the value.

**Example uses:**
- Automatically turn on a lamp when a room gets dark
- Detect whether a drawer or box is open or closed
- React to sunlight levels throughout the day

## Output values

The LDR node outputs a number between **0 and 1023**:
- **0** = complete darkness
- **1023** = very bright light

The range is large. Pair the LDR with a [Map](/docs/microflow-studio/nodes/shape/map) node to convert the range into something more useful — for example, converting 0–1023 into 0–255 to control LED brightness.

## Inputs

- **`read`** — Take a reading now. The node also reads on its own schedule, so you only need this if you want readings on your terms.

## Outputs

- **`value`** — The light level, `0`–`1023`. Higher is brighter — though which way round depends on how you wired the divider.

## Settings

- **Pin** — Which pin the component is connected to. Default `A0`.
- **Type** — Which mode the node runs in. Default `analog`.
- **Read frequency** — How often the node reads, in milliseconds. Default `25`.
- **Threshold** — How much the reading must change before the node reports it. Default `1`.
