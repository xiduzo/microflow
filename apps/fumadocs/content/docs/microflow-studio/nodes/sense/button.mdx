title: Button

A button is a simple input device that you can press to interact with your project. When you press it, it completes an electrical circuit, and when you release it, the circuit opens.

**How it works:** Connect a button to your Arduino, and the Button node sends a signal whenever someone presses or releases it. You can use each of those signals separately — for example, turning on a light when the button is pressed down, and turning it off again when it is released.

## Inputs

- **`read`** — Take a reading now. The button is polled for you, so this is rarely needed.

## Outputs

- **`event`** — Fires on every press and every release.
- **`true`** — True while the button is held down.
- **`false`** — True while the button is up.
- **`hold`** — Fires when the button has been held for longer than **Hold time**. This is how you get a long-press without building a timer.
- **`value`** — `1` while pressed, `0` while released.

## Settings

- **Pin** — Which pin the component is connected to. Default `6`.
- **Pull-up** — Use the board's internal pull-up resistor, so you can wire the component without an external one. Default `false`.
- **Pull-down** — Use an internal pull-down resistor instead. Default `false`.
- **Hold time** — How long the button must be held, in milliseconds, before `hold` fires. Default `500`.
- **Invert** — Swap the meaning of pressed and released. Useful for normally-closed wiring. Default `false`.
