---
title: Sense
description: Sense nodes read data from the physical world — buttons, sensors, switches, and external services.
---

Sense nodes are how your flow receives information from the outside world. They read from physical components connected to your Arduino, like buttons, sensors, and switches. They can also receive data from external services like MQTT.

Every flow usually starts with at least one Sense node — it is what kicks things off.

Three Sense nodes need no Arduino at all: [Hotkey](/docs/microflow-studio/nodes/sense/hotkey) listens to your keyboard, [MIDI](/docs/microflow-studio/nodes/sense/midi) listens to a MIDI controller plugged into your computer, and [MQTT](/docs/microflow-studio/nodes/sense/mqtt) listens to the network.

Sense nodes can read two kinds of signals:

- **Digital** — on or off, like a button being pressed or released
- **Analog** — a continuous range of values, like a light sensor reading from 0 to 1023

| Node | What it does |
| --- | --- |
| [Button](/docs/microflow-studio/nodes/sense/button) | Detects presses, releases, and long presses |
| [Switch](/docs/microflow-studio/nodes/sense/switch) | Reads a toggle switch, normally-open or normally-closed |
| [Hotkey](/docs/microflow-studio/nodes/sense/hotkey) | Fires from a key on your keyboard — no hardware needed |
| [Potentiometer](/docs/microflow-studio/nodes/sense/potentiometer) | Reads a knob or slider position, `0`–`1023` |
| [Analog Sensor](/docs/microflow-studio/nodes/sense/sensor) | Any analog or digital sensor that has no dedicated node |
| [LDR](/docs/microflow-studio/nodes/sense/ldr) | Reads ambient light with a photoresistor |
| [Force](/docs/microflow-studio/nodes/sense/force) | Reads pressure from a force-sensitive resistor |
| [Hall Effect](/docs/microflow-studio/nodes/sense/hall-effect) | Detects magnets and magnetic field strength |
| [Tilt](/docs/microflow-studio/nodes/sense/tilt) | Detects whether something is tilted or upright |
| [Motion](/docs/microflow-studio/nodes/sense/motion) | Detects movement with a PIR sensor |
| [Proximity](/docs/microflow-studio/nodes/sense/proximity) | Measures distance to an object |
| [NFC Reader](/docs/microflow-studio/nodes/sense/pn532) | Reads an NFC or RFID card's UID over I²C |
| [I2C Device](/docs/microflow-studio/nodes/sense/i2c-device) | Talks to any I²C device by address and register |
| [MIDI](/docs/microflow-studio/nodes/sense/midi) | Receives notes and knob values from a MIDI controller, or sends them |
| [MQTT](/docs/microflow-studio/nodes/sense/mqtt) | Sends and receives messages over a network |
