---
title: Control hardware from a Figma prototype
description: Let a Figma variable drive a physical output.
---

An interaction in a Figma prototype changes a variable. The Hardware Bridge sends the new value to Studio, and an Express node acts on it.

<Video title="Hardware in a Figma prototype" duration="6:00" script="/docs/videos/figma-bridge">
A prototype button toggling a boolean variable, and an LED on the desk following it.
</Video>

## What you need

- The Microflow Studio **desktop app**, with a flow that has at least one Express node.
- A Figma file with the [Microflow Hardware Bridge](https://www.figma.com/community/plugin/1373258770799080545) plugin running.
- The same broker and the same identifier at both ends.

## Steps

### 1. Create a Figma variable

In **Local variables**, in the **MHB** collection, create a variable whose type matches the hardware.

| Hardware | Variable type | Values |
| --- | --- | --- |
| LED on and off | Boolean | `true`, `false` |
| LED brightness on a PWM pin | Number | `0`–`255` |
| Servo angle | Number | `0`–`180` |
| Relay | Boolean | `true`, `false` |
| RGB LED | Colour | any colour |

Then build a prototype interaction that changes the variable.

### 2. Read it in Studio

1. Add a [Figma](/docs/microflow-studio/nodes/express/figma) node to your flow.
2. In its settings, select the broker and enter the identifier.
3. Select your variable from the **Variable** list.
4. Connect the Figma node's `change` or `value` output to your Express node.

The Figma node works in both directions. Its `change` output fires when the variable changes in Figma. Its `value` output carries the variable's current value.

<Callout type="info" title="Template available">
Studio ships this pattern as the **Figma to LED** template, under **Templates**.
</Callout>

### 3. Run the prototype

Run the prototype in Figma and trigger the interaction. The Figma node receives the value and passes it to the Express node.

## Convert the value on the way

A Figma variable and a hardware node do not always agree on range or type.

- **A boolean that must become a brightness.** Add a [Map](/docs/microflow-studio/nodes/shape/map) node with **From** `0`–`1` and **To** `0`–`255`.
- **A number in another range.** Use a Map node to rescale it.
- **Text that must become a number.** Use a [Function](/docs/microflow-studio/nodes/shape/function) node:

```js
// Use {{state}} to reference the connected handle value
return {{state}} === "on" ? 255 : 0;
```

## Verify it worked

1. Connect a [Monitor](/docs/microflow-studio/nodes/express/monitor) node to the Figma node's `value` output.
2. Change the variable in Figma.

Values in the Monitor mean the bridge works. If the hardware still does nothing, the fault is in the Express node or the wiring — see [Nothing happens on the board](/docs/troubleshooting/pin-conflicts).

If no values arrive, see [MQTT will not connect](/docs/troubleshooting/mqtt-cant-connect#connected-but-nothing-arrives).
