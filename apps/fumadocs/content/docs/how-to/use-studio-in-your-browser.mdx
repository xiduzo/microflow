---
title: Use Studio in your browser
description: Run Microflow without installing anything, and know what is missing.
---

Studio runs in a browser tab and reaches a board over Web Serial.

## When to use it

- You want to try Microflow without installing anything.
- Your machine does not let you install software.
- You run a workshop and prefer to send a link.

## Steps

1. Open Chrome, Edge, or Opera. Firefox and Safari cannot reach a serial port.
2. Plug the board in with a USB cable that carries data.
3. Open Studio in a tab.
4. Click **Connect board** in the sidebar. The browser opens its own port chooser.
5. Select your board and confirm.
6. Wait for the port name in the sidebar. A new board flashes firmware first, which takes up to a minute. Do not unplug it.

Studio reconnects to that board on its own from now on, including after a reload and after you unplug it.

## Verify it worked

1. Add any [Sense](/docs/microflow-studio/nodes/sense) node.
2. Add a [Monitor](/docs/microflow-studio/nodes/express/monitor) node and connect the two.
3. Touch the component and watch the Monitor.

## What the browser cannot do

The canvas, the nodes, the runtime, collaboration, the circuit view, the code view, and the sketch download are identical. Three things differ.

| | Browser | Desktop app |
| --- | --- | --- |
| Finding the board | You grant permission once per board | Automatic |
| MQTT broker configuration | Not available | **Configuration → MQTT** |
| AI provider configuration | Not available | **Configuration → LLM** |

MQTT covers the Figma and Penpot bridges. For those, or for a local AI model, use the [desktop app](https://github.com/xiduzo/microflow-t-stack/releases).

## Limits to know

- **One tab holds the port.** A second Studio tab cannot connect to the same board. Close the other tab.
- **Permission covers one origin.** Permission granted on a local dev server does not apply to the hosted app.
- **An enterprise policy can disable Web Serial.** Studio then reports the browser as unsupported, and nothing in the app overrides that.
- **A browser cannot install drivers.** If your operating system does not list the board as a serial device, see [Install board drivers](/docs/how-to/install-board-drivers).
