The [LLM node](/docs/microflow-studio/nodes/express/llm) sends a prompt to a language model on your own machine and returns the answer to your flow. Nothing leaves the computer, and it works without an internet connection.

<Callout type="warn" title="Desktop app only">
The browser build cannot configure AI providers.
</Callout>

## When to use it

- You want generated text in a prototype: a caption, a greeting, a description.
- You do not want to send sensor data or prompts to a third party.
- The project must work with no reliable network.

## Before you start

Install [Ollama](https://ollama.com) and pull a model. A small model is much faster and usually enough for a prototype.

```sh
ollama pull llama3.2
ollama list
```

Leave the Ollama server running. Studio talks to it and does not start it.

## Steps

1. Open **Configuration → LLM** in the sidebar.
2. Click **Add Provider**.
3. Set **Name** to anything, such as `Local Ollama`.
4. Set **Base URL** to `http://localhost:11434`, which is Ollama's default.
5. Leave **API Key** empty. Ollama runs on your machine and needs no authentication.
6. Save the provider, then run its test. Wait for the confirmation that the provider is reachable.
7. On the canvas, press `Cmd/Ctrl + K` and add an **LLM** node, under **Express**.
8. In its settings, select the provider and type the model name exactly as `ollama list` prints it.
9. Write the **System** and **Prompt** fields.
10. Connect something to the node's `trigger` input. The node does nothing until it is triggered.
11. Connect a [Monitor](/docs/microflow-studio/nodes/express/monitor) node in `raw` mode to the `value` output.

## Verify it worked

Fire the trigger and watch the Monitor. Expect to wait several seconds. That is normal.

While you test, connect the `thinking` output to an LED node's `true` and `false` inputs. It goes true when you trigger the node and false when the answer arrives, which tells you whether a request left at all.

## Write a better prompt

- **Set the length in the System prompt.** "Answer in one short sentence." Without it, the model writes an essay.
- **Set the character in the System prompt.** "You are a museum guide."
- **Use values from your flow** with `{{name}}` in the prompt. Each placeholder adds an input handle of that name.

```
The visitor is {{distance}} centimetres away. Greet them in one short sentence.
```

## Limits to know

- **The node is slow.** It takes seconds, not milliseconds. Put it at the end of a flow, never inside a loop that drives hardware.
- **Connect the `error` output to something visible.** A stopped Ollama server looks the same as a model that is still working.
- **Chain from `done`, not `value`.** `done` fires once, when the answer is complete.
- **The provider list is a snapshot.** Studio reads it when you open the node's settings. Reopen them after you add a provider.
