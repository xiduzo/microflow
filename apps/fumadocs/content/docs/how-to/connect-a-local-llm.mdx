The [LLM node](/docs/microflow-studio/nodes/express/llm) sends a prompt to a language model running on your own machine and puts the answer back into your flow. Nothing leaves your computer, and it works with no internet connection.

AI provider configuration is not available in the browser build.
</Callout>

## When you need it

- You want generated text in a prototype — a caption, a greeting, a description.
- You want it without sending sensor data or prompts to a third party.
- You want it to work at an exhibition with no reliable network.

## Before you start

Install [Ollama](https://ollama.com) and pull a model. A small model is dramatically faster and usually enough for a prototype:

```sh
ollama pull llama3.2
ollama list
```

Leave the Ollama server running. Studio talks to it; it does not start it for you.

## Steps

1. In Studio, open **Configuration → LLM** in the sidebar.
2. Click **Add Provider**.
3. **Name** — anything, for example `Local Ollama`.
4. **Base URL** — `http://localhost:11434`, Ollama's default.
5. **API Key** — leave empty. There is nobody to authenticate to on your own machine.
6. Save, then use the **test** control on the provider. You want the "is reachable" confirmation.
7. On the canvas, press `Cmd/Ctrl + K` and add an **LLM** node — it is under **Express**.
8. In its settings: pick the provider, type the model name exactly as `ollama list` prints it, and write the **System** and **Prompt** fields.
9. Wire something into the node's `trigger` input. It does nothing until triggered.
10. Hang a [Monitor](/docs/microflow-studio/nodes/express/monitor) in `raw` mode on the `value` output so you can read the answer.

## Verify it worked

Fire the trigger and watch the Monitor. Expect to wait a few seconds — that is normal, not a fault.

Wire the `thinking` output to an LED's `true` and `false` inputs while you are testing. It goes true the instant you trigger and false when the answer lands, which tells you at a glance whether a request left at all.

## Write a better prompt

- **Set the length in the system prompt.** "Answer in one short sentence." Without it you get an essay.
- **Set the character there too.** "You are a museum guide."
- **Use values from your flow** with `{{name}}` in the prompt. Each placeholder gives the node an input handle of that name:

  ```
  The visitor is {{distance}} centimetres away. Greet them in one short sentence.
  ```

## Gotchas

- **It is slow.** Seconds, not milliseconds. Put the node at the end of a flow, never in a loop something physical depends on.
- **Wire the `error` output somewhere visible.** A stopped Ollama server looks exactly like a model that is still thinking.
- **Chain from `done`, not `value`.** `done` fires once when the answer is complete.
- **The provider list is read when you open the node's settings.** Add a provider afterwards and you need to reopen them.
