---
title: Send a sensor reading to Figma or Penpot
description: Push a live value from a hardware sensor into a Figma variable or a Penpot design token.
---

This is the *hardware-to-design* direction of the bridge: a sensor drives a variable in your design file, and every layer that uses the variable updates live.

## What you need

- Microflow Studio with a working sensor flow, for example a [Potentiometer](/docs/microflow-studio/nodes/sense/potentiometer) on `A0`.
- A Figma file with the [Microflow Hardware Bridge](/docs/microflow-hardware-bridge) plugin running, or a Penpot file with the [Microflow plugin for Penpot](/docs/microflow-penpot-plugin) running.
- Studio and the plugin on the same MQTT broker, with the same Bridge ID. See [MQTT settings](/docs/microflow-hardware-bridge/mqtt).

## Steps

### 1. Create the variable

**In Figma:** open the local variables and select the **MHB** collection. The plugin creates it the first time it runs. Only variables in this collection are linked.

**In Penpot:** open the tokens panel and select the **MHB** token set. Keep the set active.

Pick a type that matches what your sensor produces:

| Sensor | Figma variable | Penpot token |
| --- | --- | --- |
| Button, Switch, Motion (on/off) | Boolean or Number | `number` (0 or 1) |
| Potentiometer, LDR, Force, Sensor (a range) | Number | `number`, `sizing`, `opacity`, … |
| A Function node that returns text | String | `fontFamilies`, `textCase`, … |

Give it a clear name, such as `light_level`. Bind it to a layer property, such as a width or an opacity, so you can see it change.

### 2. Add a Design variable node

1. In your flow, add a [Design variable](/docs/microflow-studio/nodes/express/figma) node.
2. Select the **Broker** that the plugin uses.
3. Pick your variable in the **variable** setting.
4. Connect your sensor to the node:
   - **Number or String variable:** connect the sensor's value to `set`.
   - **Boolean variable (Figma):** connect the sensor's `true` output to the node's `true` input, and its `false` output to `false`.
   - **On/off with a Penpot `number` token:** connect a Button's `event` output to `set`. A press sends `1` and a release sends `0`.

<Callout type="info" title="Template available">
  Studio ships this pattern as the **Sensor to Figma or Penpot** template: Potentiometer → Map (0–1023 to 0–100) → the `set` input of a Design variable node.
</Callout>

### 3. Scale the value

A sensor's range rarely matches the range your design needs. Put a [Map](/docs/microflow-studio/nodes/shape/map) node between the sensor and the Design variable node. For example, map a potentiometer's `0`–`1023` to `0`–`100`.

### 4. Run

The plugin's **MQTT** and **Microflow studio** dots should be green. Touch the sensor, and the layer should update live.

## Send a color

A Color variable has four inputs: `red`, `green` and `blue` (0–255) and `opacity` (0–100). Each input changes one channel and keeps the others. For example, connect a potentiometer through a Map (0–1023 to 0–255) to `red` to fade the color's red channel.

## Send text

A String variable takes any value on its `set` input and turns it into text. To format the text first, use a [Function](/docs/microflow-studio/nodes/shape/function) node:

```ts
function trigger(input: unknown) {
  return `Light: ${Math.round(toNumber(input))}`;
}
```

## Send several variables

Add one Design variable node for each variable. Each node can take its values from a different part of your flow.

## Verify it worked

- The plugin's **Variables** page lists your variable.
- The Design variable node shows the variable's name and current value.
- A [Monitor](/docs/microflow-studio/nodes/internal/monitor) node on the sensor's output shows values flowing.

If the plugin is connected but the variable does not change, check that:

- the variable is in the **MHB** collection (Figma) or the active **MHB** token set (Penpot),
- the node shows no error,
- the value fits the variable's type. A value that does not fit is dropped.

See [MQTT can't connect](/docs/troubleshooting/mqtt-cant-connect) for more checks.
