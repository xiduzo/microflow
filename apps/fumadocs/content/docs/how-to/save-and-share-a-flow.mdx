---
title: Export and share a flow file
description: Write a flow to a file, hand it to someone else, and open one you were sent.
---

A flow exports to a JSON file. Use a file to hand a flow over once. Use [collaboration](/docs/how-to/collaborate-on-a-flow) to work on a flow together.

## Export a flow

1. Open the flow.
2. Click the export button in the dock at the bottom of the canvas.
3. Your browser or operating system saves the file, named `<flow name>-<timestamp>.json`.

The file holds every node, every edge, every setting, and the canvas layout.

The file does not hold runtime state, the identity of the connected board, or your MQTT and AI credentials. Those live in **Configuration** and belong to your machine.

## Open a flow you were sent

1. Click the import button in the dock.
2. Select the file.

Pin numbers and node settings arrive with the flow. If the flow was built for a board you do not have plugged in, the sidebar reports no microcontroller until you connect a matching board. The flow itself opens either way.

## Commit a flow to version control

The export is JSON, so `git diff` shows a readable change. A common layout:

```
my-project/
  flows/
    main.json
    demo.json
  README.md
```

If several people edit the same flow at the same time, use [collaboration](/docs/how-to/collaborate-on-a-flow) rather than git. Yjs merges concurrent edits. Git does not merge this format well.
