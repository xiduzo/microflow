Each guide here does one specific thing. They assume you have a board connected and know what a node is — [Learn](/docs/learn) covers that.

Looking up what a node does rather than how to do something? That is the [node reference](/docs/microflow-studio/nodes). Something is broken? [Troubleshooting](/docs/troubleshooting) is organised by symptom.

## Set up

- [Connect a microcontroller](/docs/how-to/connect-a-microcontroller) — plug in a board and get to connected.
- [Use Studio in your browser](/docs/how-to/use-studio-in-your-browser) — no install, and what you give up.
- [Install board drivers](/docs/how-to/install-board-drivers) — when your computer cannot see the board at all.
- [Flash firmware manually](/docs/how-to/flash-firmware-manually) — when the automatic flash will not take.
- [Choose a board target](/docs/how-to/choose-a-board-target) — so the diagram and the sketch match your hardware.

## Build

- [Start from a template](/docs/how-to/start-from-a-template) — about thirty working flows to begin from.
- [Wire an H-bridge](/docs/how-to/wire-an-h-bridge) — driving motors in both directions.
- [Debounce a button](/docs/how-to/debounce-a-button) — one press, one event.
- [Debug with the Monitor node](/docs/how-to/debug-with-monitor-node) — find the node that is lying to you.
- [Read the circuit view](/docs/how-to/read-the-circuit-view) — build the wiring from the generated diagram.
- [Export an Arduino sketch](/docs/how-to/export-an-arduino-sketch) — run the project with Microflow closed.
