**Show code** compiles your flow into an Arduino sketch. Download it, upload it with the Arduino IDE, and the board runs on its own.

</Video>

## When to use it

- The project must run untethered, on its own power.
- You are handing the work to someone who writes Arduino code.
- You want to continue in the Arduino IDE.
- You want to read what your flow does, in C++.

## Steps

1. **Set the board target.** Open **Show code** and use the picker at the top. The default is Arduino Uno. See [Choose a board target](/docs/how-to/choose-a-board-target).
2. **Read the top of the sketch.** Microflow lists any problems there as comments, each naming a node.
3. **Click Download sketch.** You get a `.ino` file named after your flow.
4. **Open the file in the Arduino IDE.** Put it in a folder of the same name if the IDE asks. That is an Arduino convention.
5. **Select Tools → Board and Tools → Port**, then upload.
6. **Close Microflow.** The board keeps running.

## Verify it worked

Unplug the board from the computer and power it from a USB charger or a battery. If it still does what the flow did, the sketch is doing the work.

## What the icons mean

| Icon | Meaning | What to do |
| --- | --- | --- |
| None | The sketch generated cleanly. | Download it. |
| A warning triangle | The sketch generated, and part of the flow will not behave as the canvas suggests. | Read the comments at the top. See [Warnings in the generated sketch](/docs/troubleshooting/sketch-warnings). |
| A cross | Generation failed, and the download is disabled. | Fix the flow. The message names the node. |

## What does not survive the export

The sketch runs on the board, so anything that depends on your computer stops working.

- **[MQTT](/docs/microflow-studio/nodes/sense/mqtt) and the [Figma](/docs/microflow-studio/nodes/express/figma) bridge.** An ESP32 sketch can carry network code. An Uno and a Nano have no network hardware.
- **[LLM](/docs/microflow-studio/nodes/express/llm).** The model runs on your machine.
- **[Hotkey](/docs/microflow-studio/nodes/sense/hotkey) and [MIDI](/docs/microflow-studio/nodes/sense/midi).** Your keyboard and your MIDI controller are attached to the computer.
- **[Monitor](/docs/microflow-studio/nodes/express/monitor).** There is no canvas to draw on.

A flow built on those nodes stays connected to a computer. Many installations run that way, with a laptop in a cupboard.
