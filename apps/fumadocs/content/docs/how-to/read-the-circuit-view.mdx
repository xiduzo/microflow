**Show circuit** draws the wiring your flow implies: every component you have used, with the pin set in its node. Studio regenerates the diagram each time you open the view, so it always matches the canvas.

## When to use it

- You have built a flow and now need to wire the hardware.
- You wired a circuit from a kit's diagram and it does not work.
- You loaded a template and need to know which pins it expects.
- You are handing the build to someone else.

## Steps

1. Open **Show circuit** in the sidebar, under the current flow.
2. Read the whole diagram before you touch a wire.
3. Wire one connection at a time. Check the pin against the diagram before you push the wire in.
4. Wire power and ground last.

## What the diagram shows

- Every component on the canvas, with the pin from its settings.
- Power and ground for each component that needs them.

Change a pin on the canvas, and the diagram changes with it.

## What the diagram does not know

The diagram is generated from the flow, so it knows only what the flow knows.

- **Your components' quirks.** Whether a relay module is active-low, whether an RGB LED is common-anode, whether a breakout board already has a pull-up.
- **Resistor values.** An LED needs a current-limiting resistor. Use 220 Ω with a 5 V board.
- **Power budget.** A motor, a relay coil, or an LED strip draws more than a USB port supplies. Power those separately and join the grounds.

## Verify it worked

Test one component at a time. Drive each output from a [Constant](/docs/microflow-studio/nodes/generate/constant) node. If the component responds, that part of the wiring is correct.

Testing one component at a time is faster than building everything and then debugging it.

## If the wiring matches and nothing happens

See [Nothing happens on the board](/docs/troubleshooting/pin-conflicts). A pin number in a node that does not match the board is the most common cause, and the circuit view is the fastest way to find it.
