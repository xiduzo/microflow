The [MIDI node](/docs/microflow-studio/nodes/sense/midi) connects your flow to MIDI devices attached to your **computer**. A knob becomes a value in the flow. A sensor becomes a note on a synth.

A controller plugged into the computer, a knob found in CC mode, and a sensor playing a note back to a synth.
</Video>

## When to use it

- Your controller has more knobs and buttons than you want to wire.
- You are building an instrument and want sensors to play it.
- You need a physical interface for a prototype in minutes.

## Before you start

Plug the controller into the computer, not into the board. Confirm your operating system sees it:

- **macOS** — Audio MIDI Setup → Window → Show MIDI Studio.
- **Windows** — Device Manager → Sound, video and game controllers.

If your operating system does not see the controller, Studio cannot either.

## Receive from a controller

1. Press `Cmd/Ctrl + K` and add a **MIDI** node.
2. Set **Direction** to `in`.
3. Select your controller in **Device**.
4. Set **Channel** to `0`, which means every channel.
5. Set **Mode**:
   - `note` for keys and pads. Read the `note`, `velocity`, `on`, and `off` outputs.
   - `cc` for knobs and faders. Set **Control** to the controller number and read the `value` output.
6. Connect a [Monitor](/docs/microflow-studio/nodes/express/monitor) node to the outputs and move a control.

To find a knob's control number, set **Mode** to `cc`, connect a Monitor to `value`, and try control numbers while you turn the knob. Most controllers also print their mapping in the manual.

## Send to a synth

1. Set **Direction** to `out` and select the destination device.
2. Set **Mode** to `note`, then set **Note** and **Velocity**. Or set **Mode** to `song` and set a **Tempo**.
3. Connect something to the `send` input: a [Button](/docs/microflow-studio/nodes/sense/button), an [Interval](/docs/microflow-studio/nodes/generate/interval), or a [Compare](/docs/microflow-studio/nodes/decide/compare) node.

To play a note from a sensor reading, add a [Map](/docs/microflow-studio/nodes/shape/map) node. MIDI notes, velocity, and CC values all run `0`–`127`.

## Verify it worked

**Receiving:** turn a knob and watch the Monitor. If nothing arrives, set **Channel** to `0` and check that **Mode** matches what the device sends. A knob sending CC produces nothing in note mode.

**Sending:** put the synth where you can hear it, then fire the `send` input from a [Constant](/docs/microflow-studio/nodes/generate/constant) or a [Hotkey](/docs/microflow-studio/nodes/sense/hotkey) node.

## Limits to know

- **The device list is a snapshot.** Studio reads it when you open the settings. Reopen them after you plug a controller in.
- **Serial MIDI on the board is a different feature.** A generated sketch that uses MIDI claims the board's hardware serial and needs a DIN-5 jack or shield. See [the sketch warning](/docs/troubleshooting/sketch-warnings#midi). A USB controller on your computer is unaffected.
- **Channel `0` means all channels.** Narrow it once you know which channel your device uses.
