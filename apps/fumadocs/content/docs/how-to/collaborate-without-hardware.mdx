Only one person can run a flow against a board, because there is one board. Everyone else sees the canvas, with no live values — each person's Monitor nodes read their own machine's runtime.

</Video>

For the reason behind this, see [Collaboration](/docs/concepts/collaboration#one-flow-multiple-machines-one-board).

## Replace the world with generators

Swap each Sense node for a node that needs no hardware.

| Real node | Stand-in |
| --- | --- |
| Potentiometer or any analog sensor | A [Constant](/docs/microflow-studio/nodes/generate/constant) node at a representative value, such as `512` |
| Button or switch | A [Hotkey](/docs/microflow-studio/nodes/sense/hotkey) node, which has the same outputs and runs from your keyboard |
| A changing sensor | An [Oscillator](/docs/microflow-studio/nodes/generate/oscillator) node |

The Shape, Decide, and Express nodes downstream then run end to end. The Express nodes drive no hardware, but they receive values, and you can see those values.

<Callout type="info" title="Template available">
Studio ships a starting point as the **No-Hardware Playground** template: a Constant standing in for a sensor, mapped, and plotted on a Monitor.
</Callout>

## Watch with Monitor nodes

Connect a [Monitor](/docs/microflow-studio/nodes/express/monitor) node at each point you care about. Change a Constant, then follow the value through the flow. This confirms the logic without any wiring.

## Split the work

- **The person without a board** builds the flow, places Monitor nodes, names nodes, and writes Notes.
- **The person with the board** swaps the stand-ins back to Sense nodes, runs it, and reports what the hardware did.

Swapping back is quick: add the Sense node, move the edge, delete the stand-in.

## Leave context in Notes

A [Note](/docs/microflow-studio/nodes/internal/note) node holds free text on the canvas. Notes travel with the flow and every collaborator sees them. Use them for handovers:

- "Constant here. Replace with the potentiometer on A0 before running."
- "Threshold taken from yesterday's test. Verify it."
- "To do: wire the H-bridge."
