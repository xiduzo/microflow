Every Microflow term used in these docs.

### Analog pin
A pin that can read a continuous range of voltages, typically `0`–`1023` on a 10-bit Arduino. Marked `A0`, `A1`, etc. on the board.

### Bridge
Short for [Microflow Hardware Bridge](/docs/microflow-hardware-bridge), the Figma plugin that connects MQTT messages to Figma variables.

### Canvas
The blank infinite grid in Microflow Studio where you place and connect nodes.

### Component
The runtime equivalent of a node. Each node on the canvas creates a component in the Rust runtime. You need this term only if you read the source or [contribute](/docs/contributing).

### Debounce
Filtering the rapid false changes a mechanical input produces when it changes once. See [Debounce a button](/docs/how-to/debounce-a-button).

### Decide
The category of nodes that test and hold signals: Compare, Gate, Trigger, Delay.

### Digital pin
A pin whose value is either HIGH (~5 V) or LOW (0 V). Numbered without a prefix on the Arduino: pin `2`, pin `9`, etc.

### Edge
The line connecting two nodes on the canvas. Carries values from the source node's output to the target node's input.

### Express
The category of nodes that act: LEDs, servos, motors, buzzers, a Figma variable, a language model, and the Monitor node.

### Firmata and StandardFirmata
The protocol Studio uses to talk to a board over USB. StandardFirmata is the program that runs on the board. See [The microcontroller bridge](/docs/concepts/the-microcontroller-bridge).

### Flow
The whole document on the canvas — every node, every edge, every setting.

### Generate
The category of nodes that produce values without hardware: Constant, Counter, Interval, Oscillator.

### Handle
The point on a node where an edge attaches. Inputs are on the left, outputs on the right. The shape shows what the handle carries: `●` value, `◆` event, `■` state, `▶` command.

### Hot-swap
Editing a flow while it runs. Microflow applies each change at once, without restarting the connection.

### Internal
The category for the Note node, which documents a flow and changes nothing about it.

### MQTT
A lightweight publish/subscribe messaging protocol Microflow uses to connect Studio to the Hardware Bridge (and to anything else that speaks MQTT). See [Run your own MQTT broker](/docs/how-to/run-your-own-mqtt-broker).

### Node
A single building block on the canvas. Each one has settings, inputs, outputs, and a behaviour. Belongs to one of six categories: Sense, Generate, Shape, Decide, Express, Internal.

### PWM (Pulse Width Modulation)
A way to fake an analog output by toggling a digital pin extremely fast. Used to dim LEDs and run servos. PWM-capable pins on an Arduino Uno are pins 3, 5, 6, 9, 10, 11.

### Sense
The category of nodes that read the world: buttons, sensors, switches, a keyboard, a MIDI controller, the network.

### Shape
The category of nodes that transform values: Calculate, Function, Map, Smooth.

### Studio
Short for [Microflow Studio](/docs/microflow-studio), the app you build flows in. It runs on the desktop and in a browser.

### Topic (MQTT)
The address a publisher and a subscriber use to find each other. The Hardware Bridge uses topics of the form `microflow/<identifier>/figma/variable/<variable-id>`.

### Board target
The board a flow's generated sketch and wiring diagram are built for: Arduino Uno, Arduino Nano, or ESP32. See [Choose a board target](/docs/how-to/choose-a-board-target).

### Sketch
The Arduino C++ file Microflow generates from a flow. See [Export an Arduino sketch](/docs/how-to/export-an-arduino-sketch).

### Web Serial
The browser feature Studio uses to reach a serial port in Chrome, Edge, and Opera. See [Use Studio in your browser](/docs/how-to/use-studio-in-your-browser).

### Yjs
The CRDT library that powers Microflow's real-time collaboration. See [Collaboration](/docs/concepts/collaboration).
