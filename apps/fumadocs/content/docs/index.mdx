Microflow is a set of free tools for connecting physical hardware — buttons, lights, sensors, motors — and making it do something, without writing code. You build the project visually: drag blocks onto a canvas, connect them, and it runs on your board as you build.

<Video title="Meet Microflow" duration="2:30" script="/docs/videos/meet-microflow">
What Microflow is, and four things people build with it.
</Video>

## What you need

- A computer running Windows, macOS, or Linux — or Chrome, Edge, or Opera if you would rather not install anything.
- An **Arduino Uno**, **Arduino Nano**, or **ESP32**.
- A USB cable that carries data. Many cables carry power only.
- Whatever components your project needs. The first tutorial needs none.

No programming experience required.

## What people build

- Press a button, turn on a light.
- Read a light sensor, dim a lamp to match.
- Detect motion, set off a sound.
- Feed a real sensor into a Figma prototype so it reacts to the room it is in.
- Drive a servo, a stepper, an LED strip, an 8×8 matrix, or a MIDI synth.
- Ask a local AI model a question and use the answer in your flow.
