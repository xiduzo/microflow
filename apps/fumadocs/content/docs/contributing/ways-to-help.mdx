Microflow is open source. Money is one way to help, and it is not the most important one. Design, review, promotion, documentation, translation, teaching and hardware reports all make the project better.

Every way starts in the same place: [GitHub Discussions](https://github.com/xiduzo/microflow/discussions). You can also read the open threads inside the app, on the **Discussions** page.

## Help without money

| What you give | Where it starts |
| --- | --- |
| Tell other makers — write a post, or show Microflow to a maker who does not know it | [General](https://github.com/xiduzo/microflow/discussions/categories/general) |
| Record a walkthrough — show how you build one flow | [Show and tell](https://github.com/xiduzo/microflow/discussions/categories/show-and-tell) |
| Design the interface — icons, node graphics, screen layouts | [Ideas](https://github.com/xiduzo/microflow/discussions/categories/ideas) |
| Review code — read an open pull request and say what you would change | [Pull requests](https://github.com/xiduzo/microflow/pulls) |
| Improve the documentation — correct a wrong step, or write a missing page | [General](https://github.com/xiduzo/microflow/discussions/categories/general) |
| Translate — Microflow has English text only | [Ideas](https://github.com/xiduzo/microflow/discussions/categories/ideas) |
| Test hardware — connect a board that Microflow does not list yet, then report the result | [General](https://github.com/xiduzo/microflow/discussions/categories/general) |
| Answer questions from other makers | [Q&A](https://github.com/xiduzo/microflow/discussions/categories/q-a) |
| Share a flow that works | [Show and tell](https://github.com/xiduzo/microflow/discussions/categories/show-and-tell) |
| Teach with Microflow in a class or a workshop | [Show and tell](https://github.com/xiduzo/microflow/discussions/categories/show-and-tell) |
| Report accessibility problems | [Ideas](https://github.com/xiduzo/microflow/discussions/categories/ideas) |
| Report bugs | [Report a bug or request a feature](/docs/contributing/report-bug-or-request) |

## Help with money

Support pays for maintenance, new components and the hosted services that the community uses. It gives you no extra features. Every supporter gets a Supporter badge in the app and a name on the support page.

- **Monthly supporter** — choose your amount. Microflow charges it every month. You can cancel at any time.
- **One-time tip** — give once, at any amount. The payment happens one time only.
- **[GitHub Sponsors](https://github.com/sponsors/xiduzo)** — sponsor every month or one time. Your avatar also appears on the Microflow repository.

Open the **Support Microflow** page in the app to start any of the three.

## No budget and no time?

Leave a review. It is free, and it helps as much.
