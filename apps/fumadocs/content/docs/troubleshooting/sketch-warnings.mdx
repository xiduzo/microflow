---
title: Warnings in the generated sketch
description: What the triangle and the cross in the code view mean, and how to clear them.
---

Open **Show code** for a flow and Microflow checks it against the board target you have chosen before it generates the sketch. Two kinds of result:

- **A warning triangle** — the sketch generated, but part of your flow will not behave the way the canvas suggests. The download works. Read the comments at the top of the sketch; each problem names the node.
- **A cross** — generation failed. **Download sketch** is disabled until you fix it on the canvas.

Every message names the node it is about. Fix the node, not the sketch — the sketch is regenerated every time you open the view.

## Pin does not exist on this target [#pins]

> Node … uses pin *N*, which is not a usable GPIO on board target '…' (absent or reserved — e.g. ESP32 GPIO 6-11 drive the onboard flash)

The pin you asked for is not on this board, or it is reserved for something the board needs.

**Fix:** move the node to a pin the target actually has, or change the target. On an ESP32, avoid GPIO 6–11 entirely — those drive the chip's own flash memory, and using them stops the board booting.

## Not a PWM pin [#pwm]

> Node … (Servo) needs PWM on pin *N*, but pin *N* on board target '…' does not support PWM

> Node … drives brightness on pin *N*, which is not PWM-capable on board target '…' — the output degrades to on/off

Dimming an LED, setting an intensity, and driving a servo all need a pin that can hold a partial output. On an Arduino Uno or Nano those are pins **3, 5, 6, 9, 10, and 11** — the ones marked `~` on the board.

**Fix:** move the component to a PWM pin, on the board and in the node's settings.

The LED case is the sneaky one: it still works, just as on and off with nothing in between. If your LED refuses to dim and there is no error on the canvas, this warning is why.

## Out of analog inputs [#analog]

> Node … needs an analog input, but board target '…' offers only *N* and the Flow already uses them all

> Node … reads analog input A*N*, but board target '…' has only *N* analog input(s)

An Uno and a Nano have six analog inputs, A0–A5. A flow with seven analog sensors cannot run on one, however the canvas looks.

**Fix:** use fewer analog sensors, move some to digital pins if the component allows it, switch to a board with more inputs, or add an analog multiplexer and read it through an [I2C Device](/docs/microflow-studio/nodes/sense/i2c-device) node.

## Needs networking [#networking]

> Node … requires networking, which board target '…' does not offer — the generated network code assumes an ESP32-class board

You have used a node that talks to the network in a flow targeting a board with no network hardware. An Uno cannot reach a broker on its own.

**Fix:** switch the target to ESP32, or keep the networking on the computer side — Studio itself talks to MQTT brokers over your computer's connection, and that path works with any board.

## MIDI claims the hardware serial [#midi]

> Node … (Midi) uses serial MIDI on the board's primary hardware serial (31250 baud) — the USB Serial Monitor is unavailable while running, and a DIN-5 MIDI jack or shield is required

Serial MIDI on the board takes over the same lines the USB serial connection uses. Two consequences: you cannot use the Arduino IDE's Serial Monitor while it runs, and you need a physical MIDI jack or shield — a USB MIDI controller plugged into your computer is a different thing entirely.

**Fix:** if you meant a USB controller plugged into your computer, this warning does not apply to your setup and you can ignore it — but check the [MIDI node](/docs/microflow-studio/nodes/sense/midi) settings match what you actually have.

## Node ids collide [#ids]

> Node … shares the generated identifier '…' with … — rename the node ids so they differ by more than punctuation

Two nodes produce the same variable name in the generated C++, because their ids differ only by punctuation.

**Fix:** rename one of the nodes so the names differ by more than a dash or an underscore.
