If something is not behaving the way you expect, this page is the fastest way to a fix. Each entry below is a *symptom* — pick the one that matches what you are seeing.

## My board never connects
The board status in the sidebar stays at **No microcontroller connected** or **Connecting**, or ends in **Error**.

→ [Board not detected](/docs/troubleshooting/board-not-detected)

## My flow runs, but a node has no effect
Specifically: a Sense node never produces values, or an Express node does nothing physical, even though the board is connected.

→ [Pin conflicts](/docs/troubleshooting/pin-conflicts)

## My flow stops working after a while
It worked at first, then values stopped flowing or hardware froze.

→ [Flow stops mid-run](/docs/troubleshooting/flow-stops-mid-run)

## The Figma or Penpot plugin does not connect
The plugin's **MQTT** or **Microflow studio** dot is not green, or the Design variable node says a plugin is not connected.

→ [MQTT can't connect](/docs/troubleshooting/mqtt-cant-connect)

## The plugin is connected, but a variable never changes
Both dots are green, but values do not arrive. Usually the variable is outside the MHB collection or token set, or the value does not fit the variable's type.

→ [MQTT can't connect — values do not arrive](/docs/troubleshooting/mqtt-cant-connect#7-values-do-not-arrive)

## Something else

Open an issue on the [Microflow GitHub repository](https://github.com/xiduzo/microflow/issues). Include:

- Operating system
- Microflow Studio version
- A short description of what you expected and what happened
- Whether you can reproduce it from scratch (and how)

The [contributing guide](/docs/contributing) has more on how to write a good bug report.
