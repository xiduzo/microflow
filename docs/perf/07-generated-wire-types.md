# Generated wire types

Every type that crosses the Rust↔TypeScript seam is generated from the Rust
struct by [ts-rs](https://github.com/Aleph-Alpha/ts-rs) into
`apps/web/src/lib/bindings/`. TypeScript declares none of them; the browser
host reaches them through thin re-export modules that preserve the export
names the rest of the app imports.

## Where the types live

`apps/web/src/lib/bindings/` holds one file per exported type, each stamped
`// This file was generated by [ts-rs]. Do not edit this file manually.` The
directory is committed, because `tsc` and `bun test` must resolve it without a
Rust toolchain.

## Regenerating

`TS_RS_EXPORT_DIR` in `.cargo/config.toml:9` points ts-rs at
`apps/web/src/lib/bindings`. The `#[ts(export, …)]` attribute on each type
emits a test that writes the file, so regeneration is a test run:

```sh
cargo test -p microflow-core --features cloud export_bindings
cargo test -p microflow-firmata-wasm export_bindings
```

`--features cloud` is required — it implies `runtime`, and both are off by
default (`crates/microflow-core/Cargo.toml:13-22`), so a bare `cargo test`
exports none of the runtime types.

The desktop crate has its own `TS_RS_EXPORT_DIR`
(`apps/web/src-tauri/.cargo/config.toml:8`) resolving to the same directory,
so the Tauri IPC types and the browser wasm types land in one place and share
definitions rather than duplicating them.

### ts-rs attributes that carry the wire shape

The generated type must describe the **JSON on the wire**, not the Rust type
in the abstract. Three attribute families do that work:

- `rename_all_fields = "camelCase"` on tagged enums. `rename_all` only
  camelCases the variant *tags*; without `rename_all_fields` the fields inside
  struct variants stay `snake_case` and arrive `undefined` in JS. See
  `crates/microflow-core/src/flasher/driver.rs:29` and its doc comment.
- `#[ts(type = "number")]` on `u64` fields. ts-rs maps `u64` to `bigint`, but
  these cross as JSON and `JSON.parse` yields a plain `number`
  (`crates/microflow-core/src/runtime/context.rs:29`, `:33`, `:122`).
- `#[ts(inline)]` for payload structs with no independent identity, e.g.
  `FeedResult`'s pin-change and I2C-reply rows
  (`crates/microflow-firmata-wasm/src/lib.rs:81`), which stay anonymous in TS
  instead of leaking two extra binding files.

## What the `effects-sink.ts` guard proves

`apps/web/src/lib/firmata/effects-sink.ts` imports `Effects` from
`@/lib/runtime/wasm` (line 13), which resolves to the generated
`bindings/Effects.ts`. Two structures are keyed off it:

- `EFFECT_HANDLERS` at line 48, typed
  `{ [K in keyof Effects]: (fx, sink) => void }` — one handler per field.
- `APPLY_ORDER` at line 87, `as const satisfies readonly (keyof Effects)[]`,
  with `AssertOrderIsExhaustive` at line 91 erroring unless every key appears.

Because `Effects` is the generated type, both are exhaustive over the **Rust**
`Effects` struct. Adding a field to `crates/microflow-core/src/runtime/context.rs:118`
and regenerating makes both fail to compile — the same compile-time guard the
Rust `EffectsSink` trait gives the desktop host (ADR-0008).

`effects-sink.ts:17-21` derives `Wakeup`, `ComponentEvent` and
`NodeDiagnostic` by indexing into `Effects` (`Effects["wakeups"][number]`),
so they too track the generated definition.

## The invariant

**A Rust field rename must fail the TypeScript build.**

That holds as long as no TypeScript file declares a cross-language type of its
own. A hand-written mirror is structurally identical to the generated type on
the day it is written and silently wrong on the day the Rust changes: `tsc`
stays green while the browser reads `undefined` at runtime.

Concretely, a change to any type in the table above must:

1. Edit only the Rust struct.
2. Regenerate with the two `cargo test … export_bindings` commands above and
   commit the resulting `apps/web/src/lib/bindings/` diff.
3. Fix the TypeScript that `bunx tsc --noEmit` (from `apps/web`) then flags.

Step 2 is the load-bearing one: the committed bindings are what `tsc` reads.
The `check-types` job in `.github/workflows/typescript.yml` builds the wasm
glue but does not run the ts-rs export, so stale bindings typecheck cleanly
against the code that consumes them.
